# Ruffle LeafOS 工作区

面向迷你龙 Miniloong Pocket 1 的 Flash 播放器，当前为 **0.6.6 开发预览**。更新于 2026-10-24。

本轮结果：

- 声音统一使用机身音量键控制，菜单仅保留画面设置。
- 子菜单统一暂停菜单主题，按键与动作选择保留宫格。
- 宫格底栏显示四方向移动焦点，列表设置页按实际操作显示提示。
- “按键设置”合并方案选择和编辑，L/R 切换十组方案，独立保存/返回，未保存修改在切换或退出前提示处理。
- 主菜单“按键设置”支持左右即时切换方案，A 进入编辑。
- 鼠标速度归入“鼠标光标”页，集中调节速度与外观。
- “关于”集中介绍项目背景、开源来源和快捷键。
