## 快速开始

1. 下载 `ruffle-leafos-<版本>.zip`。[Releases](https://github.com/changdy/ruffle-leafos/releases)
2. 解压，将 `Apps/`、`Roms/`、`Images/` 原样合并到系统 SD 卡根目录。
3. 在 Leaf 刷新游戏列表，从 **Flash** 分类启动游戏。短按机身 **M** 打开暂停菜单。

主包附英文 Bloxorz 与测试探针。拳皇和两款死神定制版位于可选合集。可添加自己的 SWF 或游戏 ZIP。[安装、升级与添加游戏](ruffle-leafos/README.md#安装与升级)

## 掌机功能

- 每款游戏十套按键方案，可映射键盘、组合键和鼠标，支持摇杆光标、拖拽和逐键连发。
- 为支持原生保存的游戏保留五份进度，从 Apps 管理各游戏的进度与按键数据。
- 在暂停菜单保存截图或设置封面，调整画面与界面语言。标准游戏文本框支持屏幕键盘。[掌机操作](ruffle-leafos/README.md#常用操作)
