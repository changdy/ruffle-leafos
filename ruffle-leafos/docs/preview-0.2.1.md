# Ruffle Leaf 0.2.1 开发预览

> 历史版本快照：仅适用于文内版本；当前行为见 [使用说明](preview-0.6.2.md)、[当前需求](requirements.md)和 [TODO](todo.md)。

本轮新增鼠标速度三档：慢、标准、快。

从 Leaf 的 Flash 分类打开游戏，短按 Menu → 选择“鼠标速度” → 左右预览 → A 应用 → B 返回游戏。只在本次游戏有效，重开恢复标准。直接按 B 返回会丢弃未确认的预览；A 应用后仍停留菜单，便于再检查或调整。

速度只作用于摇杆鼠标和鼠标模式的十字键后备；外接鼠标不受影响。键盘模式可先选速度，切到混合或鼠标模式后生效。标准速度沿用0.2.0；工程参数分别为300/600/900屏幕像素每秒（满偏转、960×720）。

菜单顺序是：继续游戏、控制方式、鼠标速度、返回 Leaf。控制方式仍为混合/键盘/鼠标；按键、中立等待、暂停音频和正常退出保留0.2行为。

安装目标仍为 Apps/mlp1/RuffleProbe.pak/，最低 Leaf0.13.0。原 Apps/mlp1/ruffle.pak/不修改。升级前保留0.2.0包，回滚只覆盖本pak，保留游戏、Saves和.userdata。

软键盘用于无外设时向 Flash 输入文字，按用户要求后置。本轮没有12模板、持久配置、可靠存档或进度备份恢复。原生存储仍是隔离目录下的上游DiskStorageBackend；不要把退出flush请求当作可靠保存成功。

本轮完成编译和自动验证后暂停扩展，先由用户确认实际速度、四行菜单布局和按键手感。状态及改动量见本轮交付说明。
