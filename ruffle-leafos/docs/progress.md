# 工程进度

当前源码为 **Ruffle Flash 0.8.6 开发预览**。共享核心与官方渲染模块基于 Ruffle v0.7.1。目标设备为 Miniloong Pocket 1，既有实机证据来自 **Leaf 0.13.0**。[应用清单](../pak/pak.json) · [源码锁](../leaf-source.lock.json)

## 已实现

| 功能 | 当前范围 |
| --- | --- |
| Leaf 接入 | Flash 分类启动 SWF 或 ZIP，Apps 入口管理存档、按键和语言 |
| 掌机输入 | 每个游戏十套按键方案、摇杆鼠标、拖拽、方向互换和逐键连发 |
| 游戏进度 | 五槽 SharedObject、复制、有效备份回退及失败提示与重试 |
| 显示与输入界面 | 全局画面设置、中英文菜单、标准文本框软键盘、RGB PNG 截图与封面 |
| 分发 | 主安装包附 Bloxorz 与探针，三款大型定制游戏位于可选 ZIP 合集 |
| 性能与兼容 | 默认 GLES，实验 Vulkan。已有按需上传、静态资源回收、低内存退让和核心事件时序回归 |

具体操作见[使用指南](../README.md)，实现及源码入口见[工程实现细节](implementation.md)。

| 对象 | 构建与主机 | Pocket1 |
| --- | --- | --- |
| 0.8.6 当前代码中的字体、孤立对象与像素缓存优化 | ARM64 generic release 构建通过。字体全轮廓与指标对照、核心/SWF 回归及像素缓存微基准通过。[字体与孤立对象](validation/font-orphan-optimization-20261104.md) · [像素缓存](validation/cache-maintenance-20261107.md) | 这批优化的启动、首次文字、帧时间和内存收益待实测 |
| 0.8.6 分包候选 | ARM64 release 构建、发布与打包回归通过，本地生成两份完整 ZIP。报告记录的是本地打包。[分包验证](validation/release-split-20261103.md) | Bloxorz 隔离 GLES 启动、切方案、第一关移动及菜单退出通过。完整主包安装和 Leaf 扫描待验 |
| 0.8.5 正式 ZIP 路径 | 核验三个游戏 ZIP 及主 SWF/资源内容。[ZIP 与索引](validation/all-zip-list-20261103.md) | 三个游戏各有一条 Leaf 列表记录，从正式入口均进入游戏画面。修正 ZIP 解压目录后，两款死神的日志未再出现存档路径错误。完整对战和长时未验 |
| 0.8.3 稳定核心迁移候选 | ARM64 release 和升级后的核心、前端、SWF、渲染主机回归通过。[基线迁移](validation/ruffle-stable-20261102.md) | `422e3fd9…` 正式安装，拳皇与死神 3.3 完成限定 GLES 对战、暂停恢复和保存退出。Vulkan 低内存保护、拒写故障用例通过，重型游戏未通过六分钟压力。[设备记录](validation/stable-device-20261102.md) |

截图、进度拒写、损坏 SWF、GLES 内存与 ZIP 启动性能另有[专项验证](validation/README.md)。早期的方案切换、五槽重开、语言、标准文本框与 Apps 验证见[基础功能摘要](validation/stable-features.md)。

## 待完成与验收

| 方向 | 待办 |
| --- | --- |
| 当前版本 | 完成 0.8.6 双包正式安装、升级与 Leaf 列表验收。对照字体首用、长帧、缓存退让和内存增长。记录线上工作流和附件身份 |
| 输入与文本 | 可调死区、响应曲线和滞回。活动故障轴退让、双击与光标手动隐藏。坐标边界、旋转、失焦/断连、外设热插拔与休眠。自绘控件及中文组词 |
| 原生进度 | 补齐失败后退出选择和异常提示。验证满卡、只读、拔卡、断电及旧 `.sol` 迁移。实现多文件一致的历史备份、恢复、导入与导出，处理 ROM/内容身份和多进程冲突 |
| 兼容与性能 | 验证更多角色、地图、AVM1/AVM2 内容、相对资源/网络、滤镜、Stage3D 及长时音画同步。复现兼容问题后评估候选补丁。[上游修复与优化计划](upstream-roadmap.md) |
| 平台与发布 | 完成双卡、回滚/卸载保留、其他 Leaf 版本、全新主机构建及故障恢复矩阵。根据设备余量评估内存阈值 |
| 后续功能 | 临时鼠标层、多人输入与 HDMI、Apps 诊断扩展。完整运行现场快照、倒带和视频硬解待预研 |

实机验收目标包括菜单打开 ≤200 ms、导航 ≤100 ms、小型基准启动 ≤5 s，轻量 30/60 FPS 样本达到设计帧率并记录帧时间分布。耐久项目覆盖代表游戏连续两小时、100 次菜单/方案切换及 20 次可用休眠恢复。实测结合 CPU、RSS、GPU 与系统可用内存，并单独记录实体操作与人工听感。
