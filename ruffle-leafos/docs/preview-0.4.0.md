# Ruffle Leaf 0.4.0 开发预览

> 历史版本快照：仅适用于文内版本；当前行为见 [使用说明](preview-0.6.2.md)、[当前需求](requirements.md)和 [TODO](todo.md)。

本版完善自定义按键编辑、恢复默认和模板管理。入口：从 Leaf 的 Flash 分类打开游戏 → Menu → **自定义按键与模板**。原有 12 套方案及通用三模式仍可从暂停菜单切换。

## 编辑与应用

- “编辑按键”覆盖 A/B/X/Y、L1/R1/L2/R2、Start/Select、十字键四向，以及摇杆方式、十字键鼠标精调和鼠标速度。
- A 进入动作列表；L1/R1 切换常用键、字母、数字、F1–F12、鼠标/控制、Shift/Ctrl/Alt 组合、标点。上下选择，左右翻页，A 确认，B 取消。组合键保持声明的按下顺序，反序释放。
- 在编辑列表按 X 恢复当前项；“恢复当前基底全部默认”有确认步骤，恢复编辑区后仍须选择应用或保存。通用控制恢复其通用默认，12 套方案恢复各自默认；旧 cfg 文件保留。
- Menu 和菜单导航固定，不受游戏映射影响。B 从动作列表退回编辑页，再退回管理页，再关闭编辑器；管理页退出会丢弃尚未应用的草稿。Menu 可直接恢复游戏。
- “基底”左右切换会载入一套新的默认映射到编辑区；“模板管理”可以载入内置或用户模板。载入先供预览和编辑，应用后才改变游戏控制。

## 保存范围

“应用到本次”只改变当前会话。“保存此游戏默认并应用”重开同游戏仍生效。“保存为全局默认并应用”供没有游戏覆盖项的游戏继承；已有游戏覆盖优先。按键、摇杆和鼠标速度一起保存。

启动优先级：此游戏已保存映射 → 全局已保存映射 → 原有内置/通用及旧 cfg 行为。新映射是完整快照，不再叠加旧 cfg。未保存时仍保留 0.3.0 的行为。主菜单切换通用模式或其他方案属于本次修改，不会自动覆盖磁盘默认。

“清除此游戏默认”让下次启动继承全局；“清除全局默认”让无覆盖游戏下次使用内置行为。两项都需要确认，当前正在玩的映射保留。配置不写入可更新的 pak。

## 用户模板

最多保存 16 个用户模板；内置模板只读。支持另存、载入、用当前草稿覆盖、重命名、删除、导出和导入。覆盖和删除均有确认步骤。删除模板不改变已经应用到当前游戏的映射。

命名页上下选择字符、左右移动位置、X 删除、Y 加空格、A 保存、B 取消。掌机可编辑英文字母、数字、空格、横线和下划线；默认名称为 Template 01 等。导入的中文名称可正常显示。这里的命名编辑不等于向 Flash 游戏输入文字的软键盘，后者仍后置。

本机数据目录：`/mnt/sdcard/.userdata/mlp1/ruffle-probe/config/controls/`（实际随 Leaf 的 USERDATA_PATH）。

| 子路径 | 用途 |
| --- | --- |
| global.rmap | 全局控制默认 |
| games/*.rmap | 游戏专用控制默认 |
| templates/01.rmap～16.rmap | 用户模板 |
| exports/template-01.rmap 等 | 从模板菜单导出的文件 |
| imports/*.rmap | 复制到这里，再从模板管理选择导入；一次最多列出 32 个文件 |
| deleted/ | 删除或清除默认时保留的原文件 |

导入采用复制，原文件保留。版本 1 格式见 controls-format-v1.md；限制为 16 KiB，严格校验字段、按键和组合，不支持命令、脚本、任意目标路径或未知版本。坏模板可以删除，也可载入内置模板重新开始。

配置使用临时文件、同步和原子替换；更新时保留上一次有效文件为 .bak。损坏主文件优先读取有效备份，其次按配置层级回退；原损坏文件保留。写入失败显示失败，不能作为保存成功。此机制只覆盖本版控制配置，不代表游戏进度可靠存档已经完成。

## 验证与限制

31 项主机测试通过；ARM/GLES 真机自动流程验证编辑、组合键、保存、重开读取、模板另存/重命名/导出、恢复取消/应用及 12 方案回归。正式 Leaf 输入通路和最终安装校验见 iteration-0.4.0.md。本版仍为开发预览，人工操作手感、逐游戏映射适配、长期/满卡/断电矩阵继续待验收。

收藏与临时鼠标快捷层未实现；游戏改名会产生新的控制配置身份。本版以 ROM 相对路径区分同名游戏并去除挂载前缀，尚不是 F5 的完整游戏身份/进度迁移注册表。可靠游戏存档、备份恢复、休眠、全兼容和性能矩阵仍未完成。

安装位置仍为 `/mnt/sdcard/Apps/mlp1/RuffleProbe.pak/`，最低 Leaf 0.13.0。升级前保存 0.3.0 完整包，游戏、Saves 和 .userdata 保留。回滚旧播放器会保留这些新配置文件，但旧版不会读取本版的 .rmap。
