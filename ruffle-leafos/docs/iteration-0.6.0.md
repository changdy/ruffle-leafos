# 0.6.0：五份原生进度、音画与数据管理

日期：2026-10-24；基线：0.5.0。本文为该版结果摘要；当前剩余工作见 [TODO](todo.md)。0.6.1 修正生效主题覆盖和选中条，FPS 改为只显示当前值，切槽改为 M+A/B。

## 实现结果

- 参考固定 Jawaka 游戏菜单源码移植主题与面板；保留已有按键编辑和模板入口。
- 每游戏 5 份 RLS1 SharedObject 进度、北京时间、启动首帧前选档；同目录临时写入、sync、校验、原子替换及有效备份回退，失败不报告成功。
- SWF 内容指纹与本地存储 key 规范化，支持同一文件改名/移动；切换存档先提交后重启播放器，复制覆盖需确认。
- 每游戏音量/静音、三种缩放、三档画质、实际 Flash FPS 与 RAV1 持久化。
- Apps 数据管理支持按游戏/全部清理进度和按键，确认默认取消，数据移入本地归档；不 tick 演示 SWF。
