# 0.5.0：每游戏十槽与动作宫格

日期：2026-10-23；基线：0.4.1。本文为该版结果摘要；当前剩余工作见 [TODO](todo.md)。0.6.1 起快捷键改为 M+A/B，旧 M+左右停用；原生进度及音画设置由 0.6.0 补充。

## 实现结果

- 取消通用方案及全局自动继承，每游戏 10 个映射槽位；本次应用、独立保存、记忆最后选择和备份回退。
- 五列动作宫格、九类同屏 Tab、长名称适配；两组默认、单项/整槽恢复，摇杆四方向及按下独立混合映射。
- 当时 M+十字左/右循环切槽，M+十字下切换左键保持；只读查询已核对身份的内置物理手柄，普通输入仍经 Leaf 虚拟手柄交给 SDL。
- v3 数据格式兼容读取 v1/v2，模板管理与导入导出保留；切槽释放旧动作并等待按键/摇杆中立。

## 验证与限制

48 项主机测试；最终 ARM/GLES 编辑/九类 Tab/保存重开/模板/独立摇杆/光标回归；正式 Leaf 十槽循环与左键保持、591 文件校验和原模板/cfg 不变检查通过。

本版没有可靠游戏进度和音画设置；手感、收藏/临时鼠标层、长按 M 逃生、休眠与完整兼容矩阵未验收，软键盘后置。物理观察通道仅在本机 Leaf 会话验证。
