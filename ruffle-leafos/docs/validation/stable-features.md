# 基础功能实机验证摘要

以下证据来自 Pocket1 / Leaf 0.13.0 的早期构建，结果限于所列二进制和场景。当前候选状态见[工程进度](../progress.md)。

| 功能 | 构建与实机结果 |
| --- | --- |
| 原生进度 | 0.6.0（ELF `76fabc4b…`）覆盖 AVM1 五槽、AVM1/AVM2 重开、改名识别、首帧前选档、复制到槽 5、有效备份回退及隔离清理。Flash 和 Apps 正式入口、暂停恢复及退出通过。 |
| 按键方案与连发 | 0.6.8 Release（ELF `4b9295ad…`）验证双向跳空、编辑并保存新方案、清空后跳过、选择空方案并重开。连发构建 `24204369…` 的轻量夹具覆盖键盘、组合键和鼠标，49 个松开间隔为 7,639–8,463 μs。 |
| 语言、主题字形与图标 | `f03dd695…` 验证中英文即时切换、偏好重开、Inter 主题中文回退和拒写时保留旧语言。另有 Apps 与 Flash 分类图标实机预览。 |
| 标准软键盘 | `9d24c9c3…` 的 AVM1/GLES、AVM2/GLES、AVM2/Vulkan 各通过 12 阶段隔离夹具。覆盖选区、密码、Unicode、多行、长度限制与 AVM2 取消。正式启动脚本另以物理手柄事件完成输入、确认回填及菜单退出。未覆盖广泛游戏、自绘控件、实际拔插或休眠。 |
| Apps 数据管理 | `8cab7329…` 通过 130 项前端主机回归及 13 组隔离设备检查。用 25 条有数据的记录覆盖翻页、确认默认取消、仅选择记录、文件失效恢复与语言重开。批量清理前后 42 个文件的内容哈希一致，数据移到归档。样本为构造存档。 |
