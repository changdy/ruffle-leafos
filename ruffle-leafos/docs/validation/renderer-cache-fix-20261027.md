# Vulkan 位图共享与临时渲染偏好修复

日期：2026-10-27。针对 0.6.9 之后代码审查发现的两处问题。本轮没有设备，不连接 ADB，也没有安装或发布新包。

## 修复范围

- `render/wgpu/src/mesh.rs`：待完成的 Bitmap 绘制持有源 `BitmapHandle`，最终形状继续接管该句柄。纹理视图本身不能保持位图库弱缓存所指向的 Arc。相同位图在多个形状或同一形状的多个填充中可继续共享；最后一个形状/绘制命令释放后仍可回收和重新加载。
- 不将句柄加入位图对象自身缓存的 `BitmapBinds`，避免位图持有自己形成 Arc 自循环；不更改现有静态资源淘汰时机。
- `experience::Settings::requested_renderer` 只读取偏好；启动逻辑不把本次实际后端写回保存值。`recover_renderer` 仅在实际 Vulkan 出错且没有显式命令行覆盖时，把候选保存设置恢复为 GLES；Apps 和临时诊断选择不污染持久偏好。
- 保留工作区已有的全局画面设置改动。此次修复候选只收录上述修复及必要测试/文档/来源指纹；每游戏转全局路径及相应界面说明仍留在原工作区和暂存区。
