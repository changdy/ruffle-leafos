# 0.8.4：游戏列表、亮度提示与死神 3.6 收录

2026-11-02，目标为 Miniloong Pocket 1 / Leaf 0.13.0。本轮完成代码、主机验证与本地安装包构建；历史 ADB 地址连接失败，未安装到设备，也未完成新布局和亮度提示的实机验收。

## 行为与升级

- Leaf 递归扫描 `Roms/flash/` 下的 SWF，普通 `assets/` 不在跳过目录中；点号或下划线开头的路径会被跳过。随包死神 3.3 / 3.6 将资源目录改为 `_assets/`。播放器只将选中游戏根目录下的 `assets/…` 文件请求映射到相邻 `_assets/…`，保持原逻辑 URL；不修改共享核心的加载器。存在私有资源树时优先读取该树，缺文件直接报错；旧布局仍可使用。
- 主 SWF 字节和安装路径均未改变，原内容进度和同路径按键身份保持。3.6 的主文件及 554 个资源与 2026-10-31 独立交付逐项 SHA-256 相同；3.3 的全部 398 个资源保持。用户说明和目录校验清单按新路径更新。
- 升级需先备份并将旧同名游戏目录移出 `Roms/`，再完整复制新版到相同路径，最后刷新 Leaf 游戏列表；只合并复制会遗留旧 `assets/`。本轮不自动删除用户卡上的旧目录或直接修改索引数据库。探针仅留在应用内部，不再安装到 `Roms/flash/`；旧包留下的 `Leaf-GPU-Probe.swf` 可移出。
- 音量键和 M+音量键共用异步 `platform-levels` 查询，分别显示 `volume_percent` / `brightness_percent`；不重复写系统值。每 100 ms 至多安排一次读取，松键后继续观察 350 ms，保留实际数值提示约 1.5 秒。快速切换提示类型时丢弃前一类型的迟到结果；无效、缺失或未知数值不生成虚假百分比。提示覆盖游戏、暂停菜单及软键盘，由现有 GLES 叠加层呈现。
- 死神 3.6 此前仅独立交付，没有进入版本化游戏树和正式清单；本轮加入完整目录。正式清单为三个入口、959 个文件，包含 224 个主/资源 SWF。打包检查可见 SWF 必须恰好等于三个主入口，资源误放回普通目录会拒绝打包。单文件实验工具仍以内嵌原 `assets/` 路径构造 ZIP。
