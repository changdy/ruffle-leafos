## 实机检查

使用原创、无外部资源、无脚本的 320×180 三帧位图夹具。位图为 64×64，位于舞台坐标 (40,24)，顶端一至三个白色标记用于检查方向。夹具 SHA-256：`3df665123a584dac2a748973b710c23670fb7b783690b8c2a4f7d0c70a1d148e`。按键通过既有物理 evdev 测试工具注入；用户配置和进度使用独立目录隔离。

| 场景 | 结果 |
| --- | --- |
| GLES 保持比例 | PNG 为 960×540，裁去 960×720 屏幕上下各 90 像素黑边 |
| GLES 铺满屏幕 | PNG 为 960×720，保持当前非等比缩放 |
| GLES 原始大小 | PNG 为 320×180，裁去舞台外区域 |
| Vulkan 保持比例 | 实际 Vulkan 初始化及首帧日志确认，PNG 为 960×540 |
| 游戏内容与界面排除 | 五份 PNG 解码、CRC 和尺寸检查通过；各原始像素的同色邻域中心采样匹配对应夹具帧，位图范围外的背景逐像素匹配，无暂停菜单、播放器光标、FPS 或提示残留；上采样边缘允许渲染器平滑 |
| 封面首次保存/覆盖 | 首次写入 canonical PNG；置入可区分的旧内容后默认取消保持原字节，明确选择覆盖后写入有效 PNG |
| 普通照片与无副卡 | 保存到隔离系统卡 `Pictures/Ruffle Flash/`，名称包含游戏名、本地日期时间和序号；已有空副卡目录不被选择 |
| 独立挂载优先 | 在隔离副卡候选目录临时挂载独立 tmpfs，照片转存到该挂载点；照片取回后卸载。此项验证运行期选卡逻辑，不代表真实第二张 TF 卡验收 |
| 写入失败 | 暂时用文件阻挡照片目录后，界面提示失败，播放器保持暂停且可继续操作；原封面保持，测试后恢复目录 |
| 中英文界面 | 中文主菜单/截图/确认/错误页和英文截图/确认页实机抓图检查，确认默认选中取消 |
| Leaf 封面识别 | 在实际系统卡短暂放入唯一 QA ROM 和同名 PNG；刷新后游戏索引记录 `Roms/flash/RuffleScreenshot-QA-20261031.swf` 对应 `Images/flash/RuffleScreenshot-QA-20261031.png` |

封面规则还与固定 Leaf/Jawaka 源码 `internal/discovery/art_path.c` 对照：文件名去 SWF 扩展名，Images 目录平铺，PNG 优先于 JPG/JPEG，回退旧 Imgs 目录。保留原 JPEG 而添加 canonical PNG 属于替换显示结果，不删除旧文件。
