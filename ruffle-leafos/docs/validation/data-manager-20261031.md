# Flash 数据管理交互验证（2026-10-31）

本轮面向 Miniloong Pocket 1 / LeafOS 0.13.0，重整 Apps 数据管理入口、游戏列表和清理操作。用户确认以实际存档或按键配置为显示依据，包含仅记忆方案选择的 `selected.rmap`；SWF 缺失时保留数据并标记“已失效 / Unavailable”。

## 实现与兼容

- 首页保留游戏数据、批量清理、语言、返回 Leaf；游戏数据按 A 进入列表，上下选择，L1/R1 按七行翻页，A 进入单游戏操作。逐层返回和重新进入列表保留高亮位置。
- 新的只读数据清单结合实际存档、按键方案、选择记录、备份、损坏文件与 catalog 元数据。仅启动记录、内置默认和清理归档不生成条目。清理后立即重扫，无剩余数据时移出列表。
- 同路径不同内容版本的存档合并管理；清理确认使用“全部存档”，每个存档或按键目标只归属一个条目。清理仍移入 `cleared-data/`，确认默认取消。
- 新增兼容旧两行记录的第三行路径字段，详见[目录格式](../formats/data-manager-catalog.md)。旧按键 identity 可恢复路径；路径无法还原时明确显示旧数据未记录路径，不直接判为删除。
- 用户游戏名不翻译；菜单、空状态、失效标记、确认、摘要和提示提供简体中文、英语。详情使用 Flash 相对路径，避免完整挂载路径挤压文字。

## 验证边界

本轮验证数据管理的清单、导航、语言和可恢复清理。构造的存档用于验证管理与归档，不替代真实游戏进度的读写验收。未重跑全部游戏、断电、休眠或多卡拔插；SWF 状态仅检查文件存在性，不校验当前内容指纹，也不会把路径未知的历史数据标成已删除。
