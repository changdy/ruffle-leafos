# ZIP 首次解压与目录启动的 Pocket1 对照

2026-11-02 在 Miniloong Pocket 1 / leafOS 上，对比《死神 VS 火影 3.3》目录版与 ZIP 启动。测试使用相同的 0.8.4 候选播放器（SHA-256 `7dee095a5a8740abe42d7accee568a199eefdbc466735c37f4f5d36396e58fe6`）、OpenGL ES、新的隔离配置/进度和游戏 LOW 默认画质；未安装候选或覆盖正式应用。ZIP 是目录版 401 个文件逐项封装，压缩后 68,530,720 字节；解压后的 400 个清单成员及 ZIP 自身在设备逐项核验。

**测试的是启动前解压到 SD 卡、之后按普通文件读取的方案。** 当前播放器尚不支持从 ZIP 直接按需读取，这些结果不代表直接读取 ZIP 的内存、加载耗时或 FPS。ZIP 的每次首次启动均使用未存在的新目录；未清除系统页缓存，不能称作 SD 卡完全冷启动。复用缓存测试使用已解压目录。

## 启动结果

计时从测试启动脚本开始，不包含 Leaf 调度启动脚本之前的时间。首帧指 SDL 第一次 GL swap 返回，可能是加载画面或空白画面，不等于可操作主菜单；初始化完成以游戏 `games_inited` 日志标记为准。时间由设备单调时钟记录，单位秒。

| 情况 | 解压 | 首次 GL swap | 游戏初始化完成 |
| --- | ---: | ---: | ---: |
| 原目录 1 | 0 | 3.13 | 36.00 |
| 原目录 2 | 0 | 2.47 | 34.62 |
| 原目录 3 | 0 | 2.08 | 34.33 |
| 原目录 4 | 0 | 2.10 | 34.12 |
| ZIP 首次解压 1 | 5.23 | 7.43 | 39.48 |
| ZIP 首次解压 2 | 5.14 | 7.20 | 39.13 |
| ZIP 复用解压缓存 | 0 | 2.10 | 34.56 |

上述四次目录与两次 ZIP 首次解压样本的均值分别为：首次 GL swap **2.45 / 7.32 秒**，初始化完成 **34.77 / 39.31 秒**，相差约 **4.87 / 4.54 秒**。这是本轮、这张 SD 卡和游戏的有限样本；解压 5.14–5.23 秒并非其他设备的保证值。缓存只试了一次，且测试中直接使用已验证的缓存目录，没有实现完整的缓存有效性判断。

## 帧率结果

从实际进入练习场后的截图确认：两组均为一护对鸣人、魂/我爱罗援助、现世地图；Flash 目标 30 FPS。通过同一组物理按键顺序进行操作。按播放器 `leaf-perf` 完整时间窗口的帧数总和除以窗口时长计算；采样窗口不包含截图。按键注入间隔、帧调度及角色具体状态仍有差异，不能视为逐帧确定性的基准。

| 场景 | 目录版 | ZIP 解压缓存版 |
| --- | ---: | ---: |
| 静止，约 20 秒 | 30.00 FPS（20 个完整窗口） | 30.03 FPS（19 个完整窗口） |
| 同序列移动和攻击，约 15–18 秒 | 30.01 FPS（16 个完整窗口） | 30.04 FPS（13 个完整窗口） |

两组均达到该场景的 30 FPS 目标，0.03 FPS 的差异在窗口波动范围内，不能解释为性能提升。其他地图、角色、长时间、多局、Vulkan 和资源加载时卡顿未覆盖。由于两组运行时均从解压目录读取，结果符合两者在这个场景使用相同文件 I/O 路径的预期。
