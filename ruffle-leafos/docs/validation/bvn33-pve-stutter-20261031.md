# 死神 VS 火影 3.3：人机对战与换回合卡顿

2026-10-31（Asia/Shanghai），Pocket1 / Leaf 0.13.0 / RK3566 / Mali-G52。修复播放器在完整覆盖 BitmapData 前仍回读旧目标的问题。限定人机对战支持降低换回合停顿；普通战斗仍有长循环，不宣称全部卡顿消失。

## 游戏与采样

使用掌机原有 `死神VS火影3.3-脚本素材优化版/`，主 SWF SHA-256 `b4fa381c0639cbe7f9b07cc0e856674a39fc38f76c3107e19ff0e486c12cc9c6`，战斗目标 **60 FPS**，与仓库 LOW / 30 FPS 定制版区分。本次不修改游戏、398 个资源、帧率、招式、AI 或存档。已安装播放器为 0.8.2 / generic release，SHA-256 `d2dbf55f01af6d2eddf9d91c784bc9f8fe1a29931db61223579ac29e7161b6e2`。

每个会话独立 HOME、进度及按键。从菜单确认 `SINGLE VS CPU`，日志再次确认 `GameMode.currentMode 22`；一护对鸣人、魂/我爱罗援助、空座町。实体 evdev → Leaf 虚拟手柄 → SDL 注入按键，补充独立方案把肩键映射为 U 技能及 O 援助，再回放普攻、技能、援助、跳跃、冲刺和大招尝试。注入成功不代表每次尝试都在状态允许时实际出招。

每段请求约 45 秒，采集每秒性能窗口、RSS/可用内存、VM 计数及离散频率/温度。排除首个可能跨起点的窗口，仅统计未暂停、目标 60 FPS 的完整窗口，核对无选人/选图/加载切换；**回合结束及同局下一回合保留**。导航未完成或中断的会话不纳入性能表。AI、随机数和动作未逐帧固定，未锁频。最慢值不是通用加速比或逐帧 P99；嵌套调用耗时不可相加，循环与各阶段最大值的记录边界不同，也不能当成同一帧。

## 定位与实现

已安装版本两段有效战斗窗口约 44.39 / 44.37 秒、59.50 / 59.38 FPS，最长循环 99.817 / 88.250 ms，各有一次 >50 ms 循环。两段未增加换页、直接回收、分配停顿或 OOM 计数。

临时构建给 AVM2 调用加墙钟计时；在同一源码基线上用 **generic、opt-level 2、无跨 crate LTO** 编译修复前后两个诊断版本，最终源码移除逐函数计时。另有一段 A55/ThinLTO 诊断样本，最长循环约 54.4 ms，因配置不同，不用于本次修复收益计算。

同 generic 基线复现换回合 `GameState.resetFight()` **71.398 ms**，其中 `FightBar.updateBitmap()` 52.203 ms、`BitmapData.copyPixels()` **50.140 ms**。这是完整调用的主线程墙钟时间，含 CPU 执行和等待，不是 GPU 硬件耗时。

游戏先把透明空位图复制到整个血条快照，再重新绘制。`copy_on_cpu()` 虽能整片复制，仍先无条件 `dest.sync(renderer)`，回读即将被覆盖的旧 GPU 内容。修复仅在**来源与目标不同、无需混合、裁剪后的目标区域等于整个目标**时调用已有 `overwrite_cpu_pixels_from_gpu()`，随后复制来源并标记 CPU 修改。此方法已用于整图 `fillRect()`；来源仍按需同步，局部复制、透明混合、自复制保持原路径，来源不透明时继续沿用原免混合规则。

## 回归与边界

- 七项核心回归通过：整图覆盖像素和待完成读回释放、不透明来源、较大来源的偏移区域、相同自复制，以及局部复制/透明混合/GPU 来源仍要求同步。NullRenderer 故意拒绝读回，相关预期异常检查保护条件。
- ARM64 测试框架链接 SDK 的 GLIBC 2.39，直接使用系统运行库不能启动；仅在调试目录以同 SDK 独立 loader/libc/libm 运行这七项测试，未改系统库。这是核心逻辑回归，不替代正式运行库兼容验收。
- 原创 `BitmapCopyProbe` 经公开 Flash API 实际创建 GPU 修改，再逐像素核对八组情形；GLES 与实际 Vulkan 均通过 `COPY_PIXELS_PROBE PASS cases=8` 并正常退出。覆盖整图、局部、负目标坐标裁剪、透明混合、自复制、GPU 来源、不同尺寸来源和不透明来源。限定夹具通过不等于整款游戏的 Vulkan 验收。
- 正式目录版及随包 LOW 入口不变。首次资源解码、场景构建、GC、动作脚本、原有 `#1006` 和 MP3 告警仍可能带来延迟；全部角色、地图、变身、全招式、长时多局与真实手感/音频未完成。
