# Runtime provenance

The current source tree uses official ruffle-rs/ruffle stable release v0.7.1, commit `89a7049965f3090e706265670df309a5128233ac`, for the shared core, libraries, video and official rendering modules. The Leaf application is version 0.8.6 development preview; its version is independent of the upstream Ruffle version. `leaf-source.lock.json` records the upstream source and local build-input hashes, and Cargo.lock pins Rust dependencies. Ruffle is MIT / Apache-2.0; see licenses/RUFFLE-LICENSE.md.

The Leaf frontend and retained fork adaptations originally derive from aweigit/ruffle-miyooflip commit `3bc39c5e0fdbc9fcde92681706395f6ef70f991b`. That fork is retained in provenance and credits as the historical source, rather than the current shared-core baseline. `adapter/player-source.lock.json` continues to describe the original source relationship. This project does not reproduce every private leaf-12 patch.

The experimental Vulkan renderer now uses `render/wgpu/` from the same official Ruffle v0.7.1 commit, with wgpu 30, under the same MIT / Apache-2.0 licenses. It replaces the separately imported nightly-2026-03-15 renderer. `vendor/ruffle-wgpu.lock.json` records actual build-input SHA-256 values, original upstream hashes and local adaptations, and is included in package provenance. Retained local changes include bitmap-handle ownership and the test-only noop feature; they retain the upstream licenses. The bitmap ownership regression tests and their Windows host runner are local additions. The Leaf GBM/DMA-BUF/EGL presentation bridge is this project's MIT code. Vulkan, EGL and GBM driver libraries are provided by the device; no system GPU driver is replaced or redistributed.

SDL2, ALSA and the CJK menu font are reused unchanged from the user-provided leaf-12 pak; their hashes remain in provenance/runtime.lock.json. On Leaf, the launcher preloads the system SDL2 because the bundled fallback does not provide Wayland on this target. SDL2 is zlib-licensed, ALSA is LGPL, and Source Han Sans is SIL OFL. Their source references are https://github.com/libsdl-org/SDL , https://github.com/alsa-project/alsa-lib and https://github.com/adobe-fonts/source-han-sans .

New frontend, wrappers, diagnostics, build scripts and the original demo use this project's MIT license. Additional dependency license files are collected from the pinned build cache into licenses/dependencies.

Starting with 0.8.6, the main installation includes the original English Bloxorz by Damien Clarke (Roboman / DX Interactive), the Miniclip distribution downloaded unchanged from a [historical SWF mirror](https://locker.phinugamma.org/swf/miniclip/bloxorz_miniclip.swf). Its source URL, byte identity and retrieval date are pinned in `games/samples/manifest.json`, copied to `provenance/sample-games.json`. Its original in-game credits remain. Bloxorz and its assets belong to their original authors and are not covered by this project's code licenses.

Three customized games are delivered in the separate optional `ruffle-leafos-games-<version>.zip`: complete ZIPs for `拳皇Wing1.91-定制版`, `死神VS火影3.3-定制版` and `死神VS火影3.6-定制版` under `Roms/flash/`. KOF and BVN 3.3 were initially verified against the user's Pocket1 copies on 2026-10-28; the BVN 0.7.3 LOW entrypoint patch was applied locally afterward. BVN 3.6 was separately adapted and verified on 2026-10-31 and entered the bundle in 0.8.4, including its original Adobe TLF 2.0.0.232 runtime for offline UI loading (source and fingerprint in `docs/validation/bvn36-custom-20261031.md`). Repository resource trees use `_assets/`; the generated ZIPs restore the `assets/` paths without changing movie or resource bytes. Original in-game author notices remain. Game code, characters, artwork, audio and the Adobe runtime belong to their original authors or respective rights holders and are not covered by this project's code licenses. See `games/README.md` and the main package's `provenance/bundled-games.json` for source names, entrypoints and SHA-256 values. Other user-library games are not bundled.

The 0.6.0 menu rendering follows the pinned Leaf/Jawaka source in `vendor/jawaka/cmd/jawaka-menu/main.c` (seven pinned reference files; see `vendor/jawaka.lock.json`) (`jw__render_ingame_menu`, underlay and focus helpers), Copyright (c) 2026 Jawaka contributors, MIT license. Its license is included as `licenses/JAWAKA-LICENSE.txt`. Theme colors are read from the device at runtime; no user's theme assets are redistributed.

The on-screen keyboard layout and navigation are adapted from Catastrophe `include/catastrophe_widgets.h` at commit `1673e98ea1c4cda0cc00dba345e30433319b6c2f`, Copyright (c) 2026 Kevin Vranken, MIT license. This is a Rust/GL adaptation in the player window, not an external system keyboard service. `vendor/catastrophe.lock.json` pins the upstream file and retained reference excerpt; the package includes `licenses/CATASTROPHE-LICENSE.txt` and the provenance lock. No Catastrophe theme, font, or other device assets are redistributed.
