# Ruffle Leaf 0.4.1：鼠标光标设置

> 历史归档：仅代表文内版本。当前使用见[项目 README](../../README.md)，进度与待办见[工程进度](../progress.md)，工程说明见[实现细节](../implementation.md)。

本版增加光标自动隐藏，以及样式、颜色和大小设置。设备本轮调试地址为 **192.168.5.4**，使用 ADB TCP 5555。

鼠标或混合模式下，光标实际位置连续 **3.5 秒**不变会隐藏；再次移动立即显示。摇杆、十字键鼠标及外接鼠标走同一套计时。点击、按住、滚轮和键盘操作不会延长显示时间。隐藏只影响宿主光标，不改变鼠标位置、点击、拖拽或游戏推进；静止画面也会按时清除光标。菜单内的外观预览一直显示。

## 设置入口

游戏中按 Menu → 选中“鼠标速度” → **按 Y 打开光标外观**。也可从“自定义按键与模板 → 编辑按键 → 光标样式、颜色与大小”进入。

上下选项目，左右调整，X 恢复当前项。右上角即时显示预览；只有选择应用或保存后才改变游戏中的外观。B 返回并放弃未应用的预览。

| 设置 | 可选项 |
| --- | --- |
| 样式 | 箭头、十字、圆点、方框 |
| 颜色 | 白、黑、红、黄、绿、青、紫 |
| 大小 | 小16、中24、大32、特大48，按本机960×720界面比例显示 |

默认是白色箭头、中号。光标带对比描边；方框中间留空，方便看清游戏目标。箭头尖端是点击位置，十字、圆点和方框以中心为点击位置，改变大小不改变实际坐标。

“恢复光标默认”只恢复编辑区的光标外观。选择“应用到本次”“保存此游戏默认并应用”或“保存为全局默认并应用”确定范围。保存沿用当前完整控制配置；已有此游戏覆盖优先于全局默认。主菜单切换控制方式或内置方案时保留当前光标外观。

## 配置兼容

继续使用 `USERDATA_PATH/ruffle-probe/config/controls/`，不写入 pak。新版 `.rmap` 格式为 version=2，新增三项 cursor-style、cursor-color、cursor-size；同时可读取原 version=1，补上默认外观，读取时不自动重写原文件。用户模板的另存、导入和导出也包含光标外观。

旧版0.4.0不能读取新版version=2。升级保留旧安装包及升级前已有的控制配置副本；回滚时可以使用这些副本，新文件仍保留。详细格式见 controls-format-v2.md。原有14键编辑、12套方案、鼠标速度、模板管理和保存范围说明保留在 preview-0.4.0.md。

## 验证范围

41项主机测试通过；ARM/GLES隔离目录自动流程验证纯鼠标模式下的3.5秒隐藏、按住鼠标键时隐藏、移动恢复、四种样式预览、外观保存与重开、旧配置读取且不改写，以及按键编辑/模板/12方案回归。正式Leaf入口和安装文件校验结果见本批iteration-report.md及device-validation.json。

本功能管理播放器绘制的宿主光标，Flash游戏自己画出的图案由游戏控制。自动流程不能代替实际游戏手感验收；可靠游戏进度、存档备份、软键盘和休眠等后续工作继续保留。
