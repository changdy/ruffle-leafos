# Ruffle LeafOS 本轮需求 v2.8

> 历史归档：仅代表文内版本。当前使用见[项目 README](../../README.md)，进度与待办见[工程进度](../progress.md)，工程说明见[实现细节](../implementation.md)。

日期：2026-10-24（北京时间）。继承 requirements-v2.7.md；以下为本轮用户新增需求，冲突时以本文为准。

1. Flash 暂停菜单参考 GBA 使用的 Leaf 菜单源码改成同类样式。只有能直接复用或参考现有代码时才做；不可凭印象另做一个皮肤。
2. 每游戏五份独立游戏进度；有存档时先选档再开始运行；列表显示保存日期时间。原有十个**按键映射槽位**独立保留。
3. 必要的画面、声音设置。支持时增加左上角实际游戏帧率开关。
4. Apps 增加数据管理入口，能清空存档、重置按键配置。
5. 每项分别记录实现、验证与没有完成的部分。

本轮存档定义：保存 Flash 原生 SharedObject 进度，五份相互隔离。完整虚拟机、内存、计时器、音频等运行状态快照未实现；不将原生进度称为任意时刻即时存档。已有包的 supports_savestate 继续为 false。

实现与验证见 iteration-0.6.0.md，使用方法见 preview-0.6.0.md。
