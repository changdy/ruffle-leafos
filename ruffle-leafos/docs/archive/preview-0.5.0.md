# Ruffle Leaf Preview 0.5.0

> 历史归档：仅代表文内版本。当前使用见[项目 README](../../README.md)，进度与待办见[工程进度](../progress.md)，工程说明见[实现细节](../implementation.md)。

本版重点是每游戏独立的按键映射。设备为迷你龙 Miniloong Pocket 1，Leaf 0.13.0；安装包覆盖开发预览 `Apps/mlp1/RuffleProbe.pak/`。

## 使用

- 单按 M（Menu）打开暂停菜单。在「按键映射槽位」行左右预览、A 切换；「编辑当前槽位按键」可以逐键修改。
- 每个游戏有「按键映射槽位1」至「按键映射槽位10」。游戏中 **M+十字左／右** 循环切换，显示 3 秒提示。切换会释放旧槽位的按键及鼠标保持，并等待已按住的键松开、摇杆归中。
- **M+十字下** 切换「鼠标左键保持」：第一次按住左键不放，第二次松开。与摇杆按下的普通左键按住可以同时使用；暂停、失焦、断连、退出会释放。
- 修改后选「应用到当前槽位（本次）」只在此次游戏中保留；选「保存当前槽位并应用」才会永久记忆该槽位内容。最后选中的槽位会自动记忆。切换不会自动保存尚在编辑区的修改。
- 动作选择使用五列等宽宫格，所有类型 Tab 同屏显示，L1／R1 切换类型；十字键移动，A 确认，B 取消。长名称自动缩放以适应单元格。
- 编辑页的「摇杆上／下／左／右／按下」五项独立设置。可以混合键盘、组合键、鼠标移动、鼠标点击等动作。摇杆预设可以快速填充四个方向，按下动作独立保留。
- 「鼠标速度」行 Y 可以调整光标样式、颜色、大小；静止 3.5 秒隐藏，移动恢复。
- 模板管理继续支持内置模板、16 个用户模板的另存、载入、覆盖、重命名、删除，以及本地 `.rmap` 导入／导出。模板载入后需要应用或保存到当前槽位。

## 默认分组

| 输入 | 槽位1 | 槽位2 |
| --- | --- | --- |
| 十字上／下／左／右 | W／S／A／D | ↑／↓／←／→ |
| A／B／X／Y | J／K／L／I | 1／2／3／4 |
| L1／R1 | Space／Enter | Space／Enter |
| Select／Start | Tab／Esc | Tab／Esc |
| 摇杆移动／按下 | 鼠标移动／左键 | 鼠标移动／左键 |
| L2／R2 | 无，可自行设置 | 无，可自行设置 |

槽位3—10初始使用分组1的默认值，均可独立保存。「恢复当前槽位默认」按此表恢复，不会自动改写已保存文件；仍需选择保存。

## 兼容与数据

取消旧版「通用控制」和自动继承全局按键方案。旧的全局文件和 `.cfg` 原样保留，不再自动叠加。旧版此游戏 `.rmap` 在尚无新槽位1文件时兼容载入槽位1，手动保存后写入新目录，原文件保留。旧 v1／v2 模板仍可导入，新保存格式为 v3。

映射目录：`.userdata/mlp1/ruffle-probe/config/controls/`。每个游戏的十个槽位位于 `slots/<游戏标识>/slot-01.rmap` 至 `slot-10.rmap`；`selected.rmap` 记录选择。写入采用原子替换并保留有效备份；损坏文件不删除。

M 组合键通过只读查询内置物理手柄状态识别，不独占设备、不改 Leaf 的系统配置。十字方向不在 Leaf 系统快捷键可配置按键范围内；系统的截图、录屏、游戏切换及长按 M 逃生仍由 Leaf 处理。

这是开发预览。游戏进度可靠保存、软键盘、完整音画设置、收藏及休眠矩阵仍在项目待办中；实际游戏手感需要用户体验验收。
