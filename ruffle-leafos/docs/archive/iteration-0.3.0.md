# 0.3.0：内置模板与混合输入

> 历史归档：仅代表文内版本。当前使用见[项目 README](../../README.md)，进度与待办见[工程进度](../progress.md)，工程说明见[实现细节](../implementation.md)。

日期：2026-10-23；基线：0.2.1。本文为该版结果摘要；当前剩余工作见 [TODO](todo-20261024.md)。0.5.0 起取消通用/12 模板热切换和全局自动继承；内置模板保留手动载入。

## 实现结果

- 12 组内置模板、实际映射预览、本次热切换与旧 cfg 使用/忽略预览。
- 组合键顺序按下/反序释放、共享键引用计数；拖拽锁定/解除、居中、滚轮及慢/快调速。
- 正式通路核对物理 X/Y 标签，目标设备只交换 A/B；切换、暂停、失焦、断连及退出释放旧输入。

## 验证与限制

18 项主机测试；探针与《魔塔》两轮各 12 模板、每轮 214 次输入转换；正式 Leaf 模板/cfg/拖拽通路及 591 个安装文件校验通过。

本版没有自定义编辑、控制持久化、可靠原生进度或备份恢复。实际游戏模板适配、拖拽手感及人工听感未验收；Compose/RealtimeKit/MP3 警告未作为已修复项。
