## 1. 主菜单左右切换按键方案

结果：选中暂停菜单“按键设置”时，左右即时切换并记忆方案 1～10，首尾循环；A 继续直接进入当前方案编辑。切换沿用释放旧输入及归中保护，编辑页的 L/R 切换与未保存提示保留。右侧显示当前方案及左右箭头。

验证：75 项主机测试及 ARM64 cargo check 通过，包含主菜单左右切换与首尾循环。最终设备安装记录另附。

## 2. 鼠标速度移入光标设置

结果：暂停菜单移除独立“鼠标速度”，统一在“鼠标光标”中调整。该页依次提供样式、颜色、大小、鼠标速度、恢复光标默认、保存外观与返回；七行完整显示。速度左右调节立即生效，A 循环慢/标准/快，X 恢复标准。

速度沿用原主菜单的本次运行作用范围；外观继续由所有游戏全局共用，使用“保存外观（全局）”单独保存，页面明确标注作用范围。按键方案编辑内的速度仍随该方案保存。

验证：76 项主机测试及 ARM64 cargo check 通过。新增速度循环、边界、恢复、关闭页面及不意外保存外观/方案的回归；全局外观持久化与写入失败测试继续通过。

## 3. 关于与快捷键

结果：暂停菜单增加“关于”，采用同款主题面板和两个页签。左右或 L/R 切换“项目背景”“快捷键”，A/B 返回，Menu 返回主菜单；页面不推进游戏。

背景页介绍本地 SWF 播放器定位、迷你龙/LeafOS 适配、Ruffle 与 aweigit/ruffle-miyooflip 来源、Leaf/Jawaka 菜单参考、开源许可和五份原生进度的适用范围。版本号由构建版本显示，完整许可随安装包附带。

快捷键页列出 M 暂停/继续、M+A/B 换方案、M+X 方向互换、M+十字下左键保持、音量/亮度、主菜单左右换方案、编辑页 L/R、动作类别 L/R 和 Y 连发。主菜单移除原有快捷键长文案，保留“关于”入口提示。

验证：77 项主机测试及 ARM64 cargo check 通过。新增页签首尾循环、方向/肩键导航、A/B 返回、重新进入首个页签、原生进度与画面设置不变的回归；主菜单入口和退出行覆盖继续通过。
