# Ruffle Leaf 0.2.0 开发预览

> 历史归档：仅代表文内版本。当前使用见[项目 README](../../README.md)，进度与待办见[工程进度](../progress.md)，工程说明见[实现细节](../implementation.md)。

这个版本从固定的公开 Ruffle 分支构建了播放器，新增内部暂停菜单。它还未达到需求文档的日常版标准。

要求 Leaf 0.13.0 或更高版本，目标平台为迷你龙 Pocket 1（mlp1）。安装路径继续使用 `Apps/mlp1/RuffleProbe.pak/`，游戏放在 `Roms/flash/`。覆盖前保留整个旧 pak；不要删除 `.userdata`、Saves 或游戏目录。原有 `Apps/mlp1/ruffle.pak/` 不属于本工程的安装目标。

短按 Menu 打开暂停菜单；十字键上下选择，左右预览控制方式，A 确认，B 返回游戏。选择“控制方式”后 A 应用并停留在菜单，B 恢复游戏。未确认的预览不会应用。长按 Menu 的系统退出手势仍由 Leaf 处理。键盘 Esc 可以打开或关闭菜单。

控制方式只保存到本次会话：

| 方式 | 操作 |
| --- | --- |
| 混合（默认） | 十字键与 ABXY 操作游戏；摇杆移动光标，L 左键，R 右键 |
| 键盘 | 游戏旁的 cfg 优先；缺省 A 空格、B 回车、X Ctrl、Y Shift；摇杆可作方向键 |
| 鼠标 | 摇杆或十字键移动；A/Y/L 左键，B/X/R 右键；按住可拖拽 |

菜单和操作以掌机物理 A/B 为准。旧 cfg 仍可读取；新模板编辑器和 12 组模板尚未实现。启动和恢复时会等待输入回到中立，避免启动键或菜单确认键落进游戏。

菜单打开时停止游戏 tick 并暂停音频；恢复第一帧的游戏时间间隔为零。退出由主循环释放按键并请求 SharedObject flush。信号处理器只设置退出标志。

原生 SharedObject 临时接入 `SAVES_PATH/ruffle-leaf-preview/shared_objects/`，与旧播放器隔离。**这不是可靠存档验收完成**：仍沿用上游磁盘后端，稳定游戏身份、原子提交、错误反馈、备份恢复及旧档迁移均待实现。不要用本版承载唯一一份重要进度；旧存档不会自动搬入。没有任意现场即时存档。

Apps 入口使用同一播放器打开内置动画，也可通过内部菜单退出。原来 Apps 的任意键退出测试模式不适用于本版。

保留了 0.1.4 的字体发现、PulseAudio 路由、日志和环境诊断。运行日志仍为 Leaf 日志目录中的 `ruffle-probe.log`。正式画面/音频/休眠/长时兼容矩阵尚未完成；真机测试的范围以随包报告为准。

回滚时停止播放器，再用原 0.1.4 安装包覆盖 `Apps/mlp1/RuffleProbe.pak/`，保留本地数据目录。回滚不会自动转换 0.2 临时原生存储中的文件。
