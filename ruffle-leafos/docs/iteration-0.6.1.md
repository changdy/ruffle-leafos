# 0.6.1：菜单主题、紧凑提示与 M+A/B

日期：2026-10-24；基线：0.6.0。本文为该版结果摘要；当前剩余工作见 [TODO](todo.md)。菜单、快捷键和提示沿用至 0.6.2；光标变化见 [0.6.2 摘要](iteration-0.6.2.md)。

## 实现结果

- 对照当前 GBA 实图和 Jawaka 源码，补齐持久主题颜色覆盖；采用 Leaf 叶片选中条、较大字体、左右两列和底部提示。顶部保留时钟。
- FPS 只显示当前实际值；FPS、toast、左键保持底色按文字尺寸加少量边距，提示分行避免覆盖。
- M+A 上一映射、M+B 下一映射；旧 M+十字左右停用，左键保持保留。按下沿触发、按住不重复，组合输入不透传游戏。
- 构建增加 --isolated-config，绕过祖先目录 Cargo 镜像覆盖，使用工程离线缓存。

## 验证与限制

58 项主机测试；最终隔离 ARM/GLES 进度/复制/音画/管理/按键回归及截图通过；正式 Leaf 游戏/Apps、十槽循环、按住不重复、旧组合停用和左键保持通过；593 个安装文件校验。

使用自有 GLES 菜单绘制，未复刻全部系统状态栏图标；五份 SharedObject 进度沿用 0.6.0 验证，不是 GBA 即时快照。断电/重启和人工实际游戏验收仍待完成。
