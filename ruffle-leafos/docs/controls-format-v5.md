# 按键格式 v5：逐键连发

新保存使用 v5，兼容读取 v1—v4，旧文件只在主动保存时升级并保留原文备份。v5 共 46 个唯一字段：沿用 [v4](controls-format-v4.md) 的 27 个字段，另增 `turbo.0`—`turbo.13` 和 `axis-turbo.0`—`axis-turbo.4`，分别与对应实体键、摇杆四方向和按下动作匹配。

连发字段值只接受 `0`、`5`、`10`、`15`，分别表示关闭、慢速、标准、快速的目标次数/秒。只有键盘单键、组合键和鼠标左右键允许非零值；其他动作带非零连发值会被拒绝。旧 v1—v4 统一补全 19 个关闭值，读取不改写。

仍按每游戏十个方案独立保存。文件位置、完整游戏身份、selected.rmap 编号、原子写入、损坏回退规则不变；全局光标仍独立为 cursor.conf，不进入任何方案。
