# 控制配置与模板格式 v2

> 历史版本快照：仅适用于文内版本；当前行为见 [使用说明](preview-0.6.2.md)、[当前需求](requirements.md)和 [TODO](todo.md)。

0.4.1读取v1和v2，写入时使用v2。沿用v1的UTF-8、16 KiB上限、固定按键顺序和严格纯数据字段；不得包含重复、额外或可执行字段。

v2总计25个字段：v1的22个字段中version改为2，再新增：

```text
cursor-style=arrow
cursor-color=white
cursor-size=24
```

- cursor-style：arrow、crosshair、dot、square。
- cursor-color：white、black、red、yellow、green、cyan、magenta。
- cursor-size：16、24、32、48。

未知值、缺字段、额外字段、重复字段或其他版本会被拒绝并按既有规则回退。三个字段同时出现在version=1文件中也会拒绝，避免把有扩展的文件错误当作旧格式。

原v1文件读取为白色箭头、中号，不在启动时自动改写。明确保存后写v2，并把原有有效文件保留为.bak。配置的原子写入、有效备份、损坏文件保留、游戏身份核对和删除归档规则不变。

光标外观是完整控制配置快照的一部分，支持本次、此游戏默认、全局默认及用户模板。运行中的计时状态不保存：每次新会话从显示光标开始，3.5秒没有实际位置变化后隐藏。点击和虚拟按键不会续期；进入鼠标模式或应用外观后提供一段相同长度的显示预览。

v1字段与动作说明见controls-format-v1.md。v2不新增画面、音量、游戏进度或命令执行能力。回滚到只支持v1的0.4.0时，需使用升级前配置副本；新配置文件保持原样，不自动逆向转换。
