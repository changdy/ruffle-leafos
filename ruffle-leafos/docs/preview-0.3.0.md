# Ruffle Leaf 0.3.0 开发预览

> 历史版本快照：仅适用于文内版本；当前行为见 [使用说明](preview-0.6.2.md)、[当前需求](requirements.md)和 [TODO](todo.md)。

本轮提供需求第6.2节的12组内置按键方案、映射预览与本次游戏热切换。

从 Leaf 的 Flash 分类打开游戏，短按 Menu → 选择“按键方案” → 左右预览。下方四行展示实际使用的方向、摇杆、ABXY、肩键、Start/Select。A应用后仍暂停；B返回游戏并取消未应用的预览。方案只在本次有效，重开恢复通用方案和旧cfg。

旧cfg默认启用且优先，保留原文件。若它覆盖了模板需要的按键，在方案行按X预览“cfg已忽略”，A应用；也可按X重新启用。应用模板和cfg选择一起生效。只预览后按B，不改变当前方案。切换“通用控制”会回到通用方案，继续使用当前cfg开关；内置模板的摇杆行为由模板决定。

菜单顺序：继续游戏、通用控制、按键方案、鼠标速度、返回Leaf。Menu始终打开内部菜单，菜单中A确认、B返回，与游戏映射无关。应用后等待所有按键松开及摇杆回中，避免意外点击或粘键。

| 方案 | 主要用途 |
| --- | --- |
| 方向键＋Space | A空格、BCtrl、XShift、YZ；摇杆同方向键 |
| 方向键＋ZX | AZ、BX、XC、Y空格 |
| WASD＋JKL | 十字/摇杆WASD；AJ、BK、XL、Y空格 |
| 方向键跳跃 | A为Up；与十字上键共享引用计数 |
| 竞速 | 摇杆仅左右；A空格、BN、XR、Y回车；R可能重开游戏 |
| 鼠标点击 | 摇杆鼠标；A左、B右、X回车、Y空格；十字方向键 |
| 鼠标拖拽 | 摇杆鼠标；十字以1/4速度精细移动；A按住左键、B右键、X切换拖拽锁定、Y居中 |
| WASD＋鼠标 | 十字WASD、摇杆鼠标；L1右键、R1左键、L2Shift、R2按住慢速 |
| 方向键＋鼠标 | 十字方向、摇杆鼠标；L1右键、R1左键、L2Ctrl、R2按住慢速 |
| 节奏DFJK | ABXY分别D/F/J/K；摇杆不绑定 |
| Tab导航 | A回车、BEsc、XTab、YShift+Tab；L1/PageUp、R1/PageDown、L2退格、R2左键 |
| 数字技能栏 | ABXY及L1/R1/L2/R2分别1～8 |

鼠标点击/拖拽方案：L1按住慢速，R1按住快速；同时按时慢速优先，松开恢复菜单速度。L2/R2每次按下发送滚轮上/下一格，不连续重复。拖拽锁定有屏幕提示，X再次按下解除；暂停、失焦、断连、换方案或退出会释放。A按住与锁定共享左键所有权，松开其中一个不会提前结束另一个的拖拽。

内置方案默认Start=Enter、Select=Esc；未绑定肩键不发送事件。旧cfg启用时以屏幕预览为准。未实现内置模板编辑、自定义编辑、恢复/删除旧cfg、保存每游戏选择、收藏或导入导出；现有cfg仅可选择本次使用或忽略。

安装目录仍为 /mnt/sdcard/Apps/mlp1/RuffleProbe.pak/，最低Leaf0.13.0。原Apps/mlp1/ruffle.pak/保持原样。升级前备份0.2.1包，游戏、Saves和.userdata不会放在本次替换范围。

软键盘继续后置。可靠本地存档、稳定游戏身份、备份恢复、持久设置、休眠和完整兼容/性能矩阵仍未完成。退出flush请求不是可靠保存成功确认。0.2.1手动试用按用户回复记为待验收，不阻塞本批开发；本版自动验证范围和人工待验收项见本轮iteration-report.md。
