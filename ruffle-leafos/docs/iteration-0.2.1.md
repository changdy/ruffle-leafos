# 0.2.1：三档鼠标速度

日期：2026-10-23；基线：0.2.0。本文为该版结果摘要；当前剩余工作见 [TODO](todo.md)。持久化及槽位由后续版本补充，当前用法见 [0.6.2 使用说明](preview-0.6.2.md)。

## 实现结果

- 新增慢/标准/快 300/600/900 屏幕像素每秒，适用于摇杆鼠标及十字键鼠标后备；外接鼠标沿用系统行为。
- 左右预览、A 应用、B 丢弃未确认预览；当时仅本次会话有效，重开恢复标准。

本版未实现持久速度设置、12 模板或可靠游戏进度。用户暂不方便人工试用并允许后续开发，四角点击、拖拽与速度手感仍待验收；软键盘后置。
