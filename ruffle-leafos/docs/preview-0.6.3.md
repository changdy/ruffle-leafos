# Ruffle Leaf Preview 0.6.3 使用说明

适用 Miniloong Pocket 1 / Leaf 0.13.0。当前为开发预览，更新于 2026-10-24。本文包含当前完整用法；功能截图与验证见 [实现结果](implementation-report.md)，未完成项见 [TODO](todo.md)。

## 安装与入口

安装包见 [0.6.3 交付目录](../../outputs/ruffle-0.6.3/)，校验值见 [SHA256SUMS.txt](../../outputs/ruffle-0.6.3/SHA256SUMS.txt)。正常退出播放器、备份现有 `RuffleProbe.pak` 和用户数据后，将安装 ZIP 解压到 SD 卡根目录，保留包内层级，目标为 `Apps/mlp1/RuffleProbe.pak/`。

SWF 放入 `Roms/flash/`，封面放入 `Images/flash/`；有外部资源的游戏保留相对目录结构。从 Leaf 的 Flash 分类打开游戏，Apps 中的 Ruffle Leaf Preview 用于数据管理。

## 菜单与快捷键

| 操作 | 作用 |
| --- | --- |
| 短按 M（Menu） | 打开暂停菜单 |
| 菜单上下/左右，A/B | 选择/调整，确认/返回；暂停主菜单 B 继续游戏 |
| 游戏中 M+A / M+B | 上一个/下一个按键映射，10 个方案循环并提示名称 |
| 游戏中 M+X | 本次运行互换十字键与摇杆四方向，再按恢复；摇杆按下不变，退出恢复 |
| 游戏中 M+十字下 | 开关鼠标左键保持；暂停、换方案、失焦、断连或退出会释放 |
| 主菜单“鼠标光标” | 进入光标外观 |

M+十字左/右已停用。M+X 只改变本次运行的输入路由，切换按键方案保持互换状态，不改写已保存的方案。组合键按下沿触发，按住不会连续换方案；切换释放旧输入，等待按键松开及摇杆归中。暂停菜单读取 Leaf 实际主题、字体和配色覆盖。

## 按键映射

每游戏独立保存 10 个按键方案。“编辑当前映射”支持 14 个实体键、摇杆上/下/左/右及按下独立设置，可混合键盘、最多四键的组合键、鼠标移动/点击/滚轮等动作。选择入口后直接进入五列按键宫格，应用、保存及恢复操作同屏；B 直接返回暂停菜单。动作选择为五列宫格，九类 Tab 同屏，L1/R1 切换类别。

“应用到当前方案（本次）”只保留此次运行内容；“保存当前方案并应用”才写入磁盘。最后选择的方案自动记忆，切换方案不会自动保存编辑区未应用的修改。单项或整套恢复默认后仍需应用/保存。

| 输入 | 方案 1（方案 3—10 初始同此） | 方案 2 |
| --- | --- | --- |
| 十字上/下/左/右 | W/S/A/D | ↑/↓/←/→ |
| A/B/X/Y | J/K/L/I | 1/2/3/4 |
| L1/R1 | Space/Enter | Space/Enter |
| Select/Start | Tab/Esc | Tab/Esc |
| 摇杆移动/按下 | 鼠标移动/左键 | 鼠标移动/左键 |
| L2/R2 | 未绑定 | 未绑定 |

仅提供每游戏 10 个独立映射配置；通用模板、用户模板及另存、载入、重命名、删除、导入导出功能已移除。旧模板文件保留，不再读取。

旧全局映射和 ROM 旁 `.cfg` 保留，停止自动叠加。没有新方案 1 文件时，可兼容读取旧此游戏 `.rmap`；原文件保留。旧 v1/v2/v3 可读，新保存为 v4，详见 [格式说明](controls-format-v4.md)。

## 鼠标与光标

鼠标速度可选慢/标准/快。光标设置支持空心圆＋中心点、十字、圆点、方框四种样式，七种颜色和 16/24/32/48 四档大小；所有游戏共用一份外观，在暂停主菜单“鼠标光标”中预览并“保存并应用（全局）”，切换按键方案不改变光标。

默认空心圆内部透明，中心点固定为 **1×1 屏幕像素**，按点击坐标对齐；外圈随大小缩放。静止 3.5 秒隐藏、移动恢复，点击/按住/滚轮不延长显示时间。此处设置的是播放器光标，游戏自行绘制的光标由游戏决定。

旧按键文件的光标字段仅兼容校验，不再影响外观，也不会自动写入全局设置。新全局文件默认空心圆；保存采用原子替换并保留有效备份。

## 五份游戏原生进度

请先使用游戏自身的保存功能。播放器保存的是 Flash SharedObject 数据；游戏没有原生保存机制时，菜单会提示尚未产生原生进度。**五个进度槽与十个按键方案互相独立。**

- 首次使用存档 1；已有进度时重开先显示五槽列表，选档前不推进游戏。空槽从新进度开始。
- M → 保存游戏进度：提交当前原生数据。游戏显式 flush、每十秒、打开菜单和正常退出也会请求提交。
- M → 游戏存档：A 选择另槽，确认后保存当前进度并重新启动游戏，读取目标槽。
- 在列表选中其他槽后按 Y，确认后复制当前原生进度；选中当前槽按 Y 可保存。
- 时间显示最后一次数据变化的北京时间；相同数据重复提交不更新时间。单槽上限 32 MiB。
- 损坏主文件可从有效 `.bak` 回退；主备均损坏时禁止当空槽覆盖，可从 Apps 清理。

进度用 SWF 内容指纹识别，同一文件改名或移动仍可读取；内容变化会产生另一个身份。按键映射按 ROM 相对路径识别，改名或移动到不同子目录后需另行迁移按键。

完整运行现场即时快照、旧散落 `.sol` 自动迁移、进度文件导入导出和历史备份管理仍未完成。安装包备份与游戏进度备份分别保留。

## 画面与声音

M → 画面与声音，左右调整或 A 切换，即时生效并保存到此游戏配置：

- 音量 0—100%，每档 10%；静音开关。
- 保持比例、铺满屏幕、原始大小三种缩放；原始大小下大画面可能超出屏幕。
- 低/中/高三档 Flash 画质，实际差异取决于内容和后端。
- 左上角 FPS 开关，默认关；只显示当前实际 Flash 帧执行速率，按秒更新。
- 恢复默认：100% 音量、不静音、保持比例、高画质、FPS 关。

FPS、映射 toast 和左键保持提示的底色随文字尺寸收缩。人工听感、画质差异与各游戏性能仍待验收。

## Apps 数据管理与数据路径

Apps 直接进入管理界面。左右选游戏，可清空其五个进度或重置按键；也可清空全部新格式进度、重置全部按键配置。操作前二次确认，默认“取消”；清理数据移入本地归档。ROM、封面、旧 `.cfg`、未迁移的 `.sol` 和独立音画配置保留。

以下路径对应正式启动脚本，根目录由 Leaf 当前所选卡环境提供：

| 数据 | 位置 |
| --- | --- |
| 按键映射 | `$USERDATA_PATH/ruffle-probe/config/controls/`；映射为 `slots/<路径标识>/slot-01.rmap`—`slot-10.rmap`，`selected.rmap` 记忆选择 |
| 全局光标 | `$USERDATA_PATH/ruffle-probe/config/controls/cursor.conf` |
| 原生进度 | `$SAVES_PATH/ruffle-leaf-preview/shared_objects/slots-v1/games/<内容指纹>/slot-1.rls`—`slot-5.rls` |
| 音画配置 | `$USERDATA_PATH/ruffle-probe/config/audiovisual/<内容指纹>.rav` |
| 清理归档 | `$SAVES_PATH/ruffle-leaf-preview/shared_objects/cleared-data/` |
| 运行日志 | `$LOGS_PATH/ruffle-probe.log`，上次日志为 `.previous` |

设备已安装 0.6.3 的记录及升级前 0.6.1 备份路径见 [installation.json](../../outputs/ruffle-0.6.3/installation.json)。升级/回滚前同时保留安装包、控制目录与存档目录；完整跨版本保留矩阵、断电/重启/休眠与人工游戏验收继续列在 [TODO](todo.md)。
