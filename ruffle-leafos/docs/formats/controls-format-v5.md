# 按键格式 v5：逐键连发

新保存使用 v5，兼容读取 v1—v4，旧文件只在主动保存时升级并保留原文备份。v5 共 46 个唯一字段：沿用 [v4](controls-format-v4.md) 的 27 个字段，另增 `turbo.0`—`turbo.13` 和 `axis-turbo.0`—`axis-turbo.4`，分别与对应实体键、摇杆四方向和按下动作匹配。

连发字段值只接受 `0`、`5`、`10`、`15`，分别表示关闭、慢速、标准、快速的目标次数/秒。只有键盘单键、组合键和鼠标左右键允许非零值；其他动作带非零连发值会被拒绝。旧 v1—v4 统一补全 19 个关闭值，读取不改写。

仍按每游戏十个方案独立保存。文件位置、完整游戏身份、selected.rmap 编号、原子写入、损坏回退规则不变；全局光标仍独立为 cursor.conf，不进入任何方案。

2026-10-25 起允许 19 个绑定全部为 `none` 的空方案读写与应用；仍保存为 v5，不增加字段，其他严格校验不变。`selected.rmap` 也允许携带空映射副本，以便记忆手动选中的空方案。旧播放器曾拒绝全空映射，回滚时可能将其视为无效并尝试备份或槽位默认值。

缺少文件时，方案 1、2 保留原默认键位，方案 3—10 默认 `bind.*=none`、`axis.*=none`、`stick=none`、`fine=false`、全部连发为 `0`；空默认使用兼容的 `base=13`、`mode=hybrid`、`speed=normal`，不靠 base 判断是否为空。已有文件和备份继续按原优先级读取，不因更新重写。M+A/B 仅在绑定不全空或 `fine=true` 的方案间循环；菜单仍可访问所有槽位。
