# 音画与渲染设置：RAV1 / RAV2

0.7.0 开发预览。实现为 `experience::Settings`；此文件只保存每游戏的画面和渲染偏好，不保存完整运行现场或 SharedObject 进度。

## 路径与身份

位于控制目录的父目录下 `audiovisual/<SWF 内容身份>.rav`，正式启动时通常为 `$USERDATA_PATH/ruffle-probe/config/audiovisual/`。与进度使用同一内容身份，SWF 改名或移动仍匹配；内容变化会产生新身份。加载不创建或改写文件。

## RAV2 写入格式

固定 18 字节，小端整数，无额外尾随数据。

| 字节偏移 | 内容 | 合法值 |
| --- | --- | --- |
| 0—3 | ASCII 魔数 | `RAV2` |
| 4 | 旧游戏音量 | 读取允许 0—100，但不应用；新写固定 100 |
| 5 | 旧静音 | 读取允许 0/1，但不应用；新写固定 0 |
| 6 | 缩放 | 0 保持比例、1 铺满屏幕、2 原始大小 |
| 7 | Flash 画质 | 0 低、1 中、2 高 |
| 8 | FPS 显示 | 0 关、1 开 |
| 9 | 渲染偏好 | 0 OpenGL ES、1 Vulkan（实验） |
| 10—17 | 校验 | 对字节 0—9 的 FNV-1a 64 位，小端 |

FNV 初值 `0xcbf29ce484222325`，每字节先异或，再乘 `0x100000001b3`，按 64 位溢出。文件缺失，或长度、魔数、字段范围或校验错误时使用默认：保持比例、高画质、FPS 开、OpenGL ES；不会用修复值自动覆盖损坏文件。有效 RAV1/RAV2 中保存的 FPS 开关继续优先读取，包括已保存的关闭状态，不批量迁移。

## RAV1 兼容

旧版固定 17 字节：魔数 `RAV1`，字节 4—8 与上表相同，字节 9—16 是对字节 0—8 的同算法校验；渲染偏好视为 OpenGL ES。只读旧文件，不在加载时升级。主动修改缩放、画质、FPS 或确认接口切换后写 RAV2。旧版播放器不能读取 RAV2，降级时可能回到默认画面选项；此格式独立于 RLS1 游戏进度。

## 应用、重启与失败

- 缩放、画质和 FPS 即时应用；“恢复默认画面设置”只重置这三项，保留渲染偏好。
- 接口切换先确认，默认取消。已使用的接口不重启；选择另一接口后，原生进度提交成功、退出循环再次提交成功，才原子保存偏好并重启，保留当前进度槽。
- 写入采用同目录临时文件、文件 sync、原子替换及目录 sync；不把设置写入 pak。
- 按保存偏好启动 Vulkan 失败时，记录原因、提示用户、写回 GLES 偏好并使用 GLES。已捕获的运行期 GPU 错误会尝试提交进度、恢复下一次 GLES 偏好并结束会话。
- `--renderer opengl-es|vulkan` 只覆盖当前运行，显式指定 Vulkan 的初始化失败直接报错；通过菜单再次切换时清除旧命令行覆盖。Apps 管理入口始终使用 GLES。
- 偏好与实际接口分开记录，菜单“使用中”和日志 `leaf-graphics actual=` 以实际后端为准。
