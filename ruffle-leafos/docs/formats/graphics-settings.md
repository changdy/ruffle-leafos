# 音画与渲染设置：RAV1 / RAV2

0.7.0 开发预览。实现为 `experience::Settings`；所有游戏共用一份全局画面与渲染偏好，不保存完整运行现场或 SharedObject 进度。

## 全局路径与旧配置

`Settings::global_path` 固定使用控制目录父目录下的 `audiovisual/global.rav`，正式启动时为 `$USERDATA_PATH/ruffle-probe/config/audiovisual/global.rav`。路径不依赖 SWF 内容、名称、目录或存档槽位，所有游戏共用。诊断显式指定另一控制目录时，对应配置根目录可独立隔离。

旧的 `audiovisual/<SWF 内容身份>.rav` 文件保留但停止读取，不自动选择、合并或迁移其中任何游戏的设置。没有有效全局文件时使用统一默认值；加载不创建或改写文件。

## RAV2 写入格式

固定 18 字节，小端整数，无额外尾随数据。

| 字节偏移 | 内容 | 合法值 |
| --- | --- | --- |
| 0—3 | ASCII 魔数 | `RAV2` |
| 4 | 旧游戏音量 | 读取允许 0—100，但不应用；新写固定 100 |
| 5 | 旧静音 | 读取允许 0/1，但不应用；新写固定 0 |
| 6 | 缩放 | 0 保持比例、1 铺满屏幕、2 原始大小 |
| 7 | Flash 画质 | 0 低、1 中、2 高 |
| 8 | FPS 显示 | 0 关、1 开 |
| 9 | 渲染偏好 | 0 OpenGL ES、1 Vulkan（实验） |
| 10—17 | 校验 | 对字节 0—9 的 FNV-1a 64 位，小端 |

FNV 初值 `0xcbf29ce484222325`，每字节先异或，再乘 `0x100000001b3`，按 64 位溢出。文件缺失，或长度、魔数、字段范围或校验错误时使用默认：保持比例、高画质、FPS 开、OpenGL ES；不会用修复值自动覆盖损坏文件。全局文件中保存的开关对所有游戏生效，包括 FPS 关闭。

## RAV1 兼容

旧版固定 17 字节：魔数 `RAV1`，字节 4—8 与上表相同，字节 9—16 是对字节 0—8 的同算法校验；渲染偏好视为 OpenGL ES。全局路径仍兼容此格式，不在加载时升级；兼容解码不代表继续读取旧的每游戏路径。主动修改缩放、画质、FPS 或确认接口切换后写 RAV2。旧版播放器使用每游戏路径，不读取新的全局文件；此格式独立于 RLS1 游戏进度。

## 应用、重启与失败

- 缩放、画质和 FPS 即时应用并保存为全局值，其他游戏后续启动沿用；“恢复默认画面设置”只重置这三项全局值，保留全局渲染偏好。
- 接口切换先确认，默认取消。已使用的接口不重启；选择另一接口后，当前游戏原生进度提交成功、退出循环再次提交成功，才原子保存全局偏好并重启当前游戏，保留当前进度槽。其他游戏后续启动使用同一全局接口。
- 写入采用同目录临时文件、文件 sync、原子替换及目录 sync；不把设置写入 pak。
- 按全局偏好启动 Vulkan 失败时，记录原因、提示用户、写回全局 GLES 偏好并使用 GLES。按全局偏好运行时捕获 GPU 错误，会尝试提交进度、恢复后续游戏共用的 GLES 偏好并结束会话。
- `--renderer opengl-es|vulkan` 只覆盖当前运行，显式指定 Vulkan 的初始化失败直接报错；其运行期错误也不改写全局偏好。通过菜单再次切换时清除旧命令行覆盖。Apps 管理入口始终使用 GLES；临时接口与已保存偏好分开，Apps 或诊断会话调整其他画面选项时保留全局接口值。
- 偏好与实际接口分开记录，菜单“使用中”和日志 `leaf-graphics actual=` 以实际后端为准。
