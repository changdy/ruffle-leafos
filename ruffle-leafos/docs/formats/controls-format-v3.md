# 本地按键映射格式 v3

> 旧版格式契约：保留用于兼容读取。当前写入格式见 [v5](controls-format-v5.md)，当前操作见[项目 README](../../README.md)。

继承 v2 的严格字段校验、文件大小限制、普通文件检查、原子写入、备份与恢复方式；不含脚本、命令或动态执行入口。编码为 UTF-8，以 LF 分行。

v3 恰好30个字段：`version=3`、`name`、`identity`、`base`、`mode`、`speed`、`stick`、`fine`，14个 `bind.0`—`bind.13`，5个 `axis.0`—`axis.4`，以及 `cursor-style`、`cursor-color`、`cursor-size`。重复、缺失、未知字段均拒绝。

`axis.0`—`axis.3` 为摇杆上、下、左、右；`axis.4` 为摇杆按下。所有轴向可以选择与普通按钮相同的动作。`pointer-0`—`pointer-3` 代表持续向上、下、左、右移动鼠标，速度随摇杆偏移量变化。键盘或点击动作使用0.45按下／0.30释放阈值，避免边界抖动；径向死区0.18。键盘组合最多4个不同按键，按记录顺序按下、反序释放，共享动作使用引用计数。

`stick=custom` 表示逐方向编辑；`mouse`、`directions`、`steering`、`none` 表示最后使用的填充预设。v3运行时以五个显式 `axis.*` 为准。旧 v1／v2没有这些字段，读取时根据其原摇杆方式生成四个方向，按下动作保持未绑定，不改写原文件。

`base=13` 是新分组1，`base=14` 是新分组2；0—12保留旧格式兼容，旧内置模板仍可手动载入。恢复槽位默认根据槽位编号选择分组1／2，不根据旧基底选择。

每游戏目录为 `slots/<原有游戏FNV标识>/`。各槽位文件均包含完整 `identity` 防止哈希碰撞误读或覆盖；仅路径哈希相同不足以匹配。相同游戏路径在 SD 挂载点变更和 `FLASH` 目录大小写变化后仍可匹配，不合并不同子目录或游戏文件名。

`selected.rmap` 同样采用 Record 格式，名称严格解析为 `Slot 1`—`Slot 10`，身份必须匹配；其映射副本不代替槽位文件。未保存的本次应用映射不会借由记忆选择而在下次启动中恢复。

槽位内容文件保存时保留 `.rmap.bak`；主文件损坏可以读备份，身份冲突则拒绝载入和覆盖。新建及启动不批量生成十份文件。旧全局映射不参与新槽位启动继承；旧此游戏映射只在尚无槽位1文件时进行内存兼容读取。

## 0.6.2 光标样式兼容

cursor-style可选ring-dot、crosshair、dot、square。默认ring-dot为透明空心圆加固定1×1屏幕像素的中心点；外圈使用原16/24/32/48四档大小，七色不变。旧arrow作为读取别名映射到ring-dot，不再提供箭头模型；打开旧v2/v3文件不改写，主动保存才写ring-dot并按已有机制备份旧内容。旧v1缺少光标字段时使用新的默认样式。

字段数量和version=3不变，未知标识仍拒绝。回滚到不识别ring-dot的旧播放器时，可使用升级前控制备份或原arrow文件备份。
