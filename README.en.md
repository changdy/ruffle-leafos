## Quick start

1. Download `ruffle-leafos-<version>.zip`. [Releases](https://github.com/changdy/ruffle-leafos/releases)
2. Extract the ZIP and merge `Apps/`, `Roms/` and `Images/` into the root of the system SD card.
3. Refresh the Leaf game list and launch a game from **Flash**. Tap the physical **M** button to open the pause menu.

The main ZIP includes English Bloxorz and a diagnostic demo. The optional collection contains customized editions of KOF and two Bleach vs Naruto games. You can add your own SWFs or game ZIPs. [Installation, upgrades and adding games](ruffle-leafos/README.en.md#installing-and-upgrading)

## Handheld features

- Map buttons to keyboard keys, shortcuts or mouse actions in ten profiles for each game. Use the stick as a pointer, drag with a shortcut, or hold a button for turbo.
- Keep five progress slots for games with native saves. Manage progress and controls from Apps.
- Save screenshots or game covers, adjust the display, or switch interface languages from the pause menu. Use the on-screen keyboard with standard game text fields. [Handheld controls](ruffle-leafos/README.en.md#everyday-controls)
